# 第一阶段总结（2026-09-16 至 2026-09-18）

目标回顾：在一台 RTX 4090 D（24 GB）的 Windows 机器上，把"数学妈妈"儿童数学视频需要的本地生成能力全部跑通，并形成可重复的流程。结果：**能力全部跑通，流程已收敛成一个镜头说明书驱动的流水线**；主观质量验收和真人样音、骨骼角色两项资产仍待补。

## 关键决策与依据

1. **两个隔离环境**：ComfyUI 便携包（图片、基础视频、Fun Control）与 Wan2GP（口型、音频、VACE）互不共享依赖；ComfyUI 未装任何第三方节点，已冻结为 baselines/comfyui-v1。
2. **权重全部锁定**：130 个文件、120.33 GiB，仓库提交号 + SHA256 入清单，分块续传下载器绕开 Hugging Face 直连停滞。
3. **控制信号选线稿不选深度**：同种子对照证明深度灰度对 Fun Control 5B 无效，Canny 线稿几何跟随好。
4. **角色一致性走参考图不走 LoRA**：VACE 的主体参考在中景以上可靠，且不需要训练；LoRA 留作兜底。
5. **对话不拆镜头**：VACE + Multitalk 在同一镜头内完成两人轮流说话，避免特写拼接。
6. **音频先行的时间轴**：先合成台词得到时长，帧数和动作窗口由时间轴推导，这是语音与动作对齐的机制。
7. **加速**：Triton + SageAttention 2 使去噪快约 35%，画面无退化，已设为默认。

## 已知边界（都有实验证据）

- 构图只跟随一半：模型偏好中景，近景被拉成半身、远景被拉成中景。近景另用口型模型，远景不放角色。
- 人偶在画面中不足一半高度时，参考图绑不到轮廓上。
- 参考图裁到大腿会让下装漂色；全身参考图 + 在描述里写明服装可解决。
- Blender 的材质贴图对线稿链路无意义；VACE "原样"模式是复制不是重绘，不能拿来保色换风格。
- 圆柱人偶没有脸和手，表情、手指由模型自由发挥。
- 单次生成受显存限制在 49–81 帧，更长镜头靠滑窗拼接。
